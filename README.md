# SIEM Log Analysis Lab

## Objective

Practice investigating security events from a Junior SOC Analyst standpoint using a SIEM.

## Tools Used

- Wazuh SIEM

- Windows Event Logs

- PowerShell

- Command Prompt

## Lab Activity

I generated basic Windows activity such as opening PowerShell, using Command Prompt, and reviewing logs inside the SIEM.

## What I Looked For

- Event time

- Host/computer name

- User account

- Process name

- Command used

- Event description

- Whether the activity looked normal or suspicious

## Example Investigation

Alert/Event Reviewed: PowerShell or CMD activity

Verdict: Benign

Reason:

The activity was generated by me during lab testing.

## Lessons Learned

- How to search SIEM logs

- How to review event details

- How to determine whether activity is benign or suspicious

- How to document findings like a SOC analyst
